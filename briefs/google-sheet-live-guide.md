# เชื่อมสินค้าบนเว็บกับ Google Sheet แบบ LIVE

เว็บดึงสินค้าจาก Google Sheet ได้สด — แก้ในชีต เว็บอัปเดตตาม (ทุก ~5 นาที)
ตอนนี้ชีตยัง **ตั้งเป็นส่วนตัว** เว็บเลยใช้ชุดข้อมูลตั้งต้น 84 รายการไปก่อน พอทำตามด้านล่างจะสลับเป็นสดทันที

---

## ⚠️ สำคัญเรื่องราคา (อ่านก่อน)

ลิงก์ CSV ที่ publish ออกมา = **ใครก็เปิดดูได้** ถ้าแท็บนั้นมีราคา/ต้นทุน ข้อมูลจะหลุด
👉 ให้ทำ **แท็บใหม่แยกต่างหาก** ที่มีแค่ 3 คอลัมน์: `รหัสสินค้า` · `ชื่อสินค้า` · `หน่วย`
(จะเพิ่ม `หมวด` กับ `ขายดี` ก็ได้) แล้ว publish เฉพาะแท็บนั้น — ห้ามมีคอลัมน์ราคาเด็ดขาด

> ถึงเว็บจะอ่านแค่ 3 คอลัมน์อยู่แล้ว แต่ลิงก์ CSV สาธารณะจะเผยทุกคอลัมน์ในแท็บ จึงต้องแยกแท็บ

หัวตารางที่เว็บรู้จัก (ตั้งชื่อคอลัมน์อย่างใดอย่างหนึ่ง):
- รหัส: `Product code` / `รหัส`
- ชื่อ: `Product Name` / `ชื่อไทย` / `ชื่อสินค้า`
- หน่วย: `Unit` / `หน่วย`
- (ถ้ามี) หมวด: `หมวด` / `Category` · ขายดี: `ขายดี` / `best` (ใส่ 1 หรือ x)

---

## ขั้นตอน

1. เปิดชีต → สร้างแท็บใหม่ (เช่นชื่อ **WEB**) ใส่แค่ รหัส/ชื่อ/หน่วย
2. เมนู **ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ (Publish to web)**
3. เลือก **แท็บ WEB** และรูปแบบ **CSV** → กด **เผยแพร่** → คัดลอกลิงก์
4. ในโฟลเดอร์ `web/` สร้างไฟล์ `.env.local` แล้วใส่:
   ```
   PRODUCTS_SHEET_CSV_URL=<ลิงก์ CSV ที่คัดลอกมา>
   ```
5. รันเว็บใหม่ (`npm run dev`) — สินค้าจะมาจากชีตสด

---

## แบบปลอดภัยกว่า (สำหรับเวอร์ชันเต็ม)

ถ้าไม่อยากเปิด publish สาธารณะเลย ใช้ **Google Sheets API + Service Account**:
แชร์ชีตให้อีเมล service account (คงเป็นส่วนตัว) แล้วเว็บอ่านผ่าน API ฝั่งเซิร์ฟเวอร์
ตั้งค่านี้ซับซ้อนกว่า — ผมช่วยทำตอนทำเวอร์ชันเต็มได้

---

## หมายเหตุ

- เว็บ **ไม่เคยอ่านคอลัมน์ราคา** ต่อให้เผลอใส่มาก็ไม่ขึ้นเว็บ (แต่ลิงก์สาธารณะยังเผย จึงต้องแยกแท็บ)
- ถ้าลิงก์ล่ม/ผิด เว็บจะกลับไปใช้ชุดตั้งต้นอัตโนมัติ ไม่พัง
- ตั้ง `PRODUCTS_SHEET_CSV_URL` บน host ตอน deploy ด้วย (เช่น Vercel → Environment Variables)
