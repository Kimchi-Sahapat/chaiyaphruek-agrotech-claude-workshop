## เส้นทางหลัก (happy path)

```
หน้าแรก → สินค้า → เพิ่มลงรายการ → รายการของฉัน → ยืนยัน(ชื่อเล่น+เบอร์)
   → ส่งรายการทางไลน์ → ลูกค้ากดส่ง → เข้ากล่องข้อความร้าน
   → ร้านแจ้งราคา/เช็กของ/แนะนำ → ปิดการขาย
```

1. **หน้าแรก** — ปุ่มใหญ่ 4 ปุ่ม: ดูสินค้า/สั่งของ · อ่านความรู้ · โทรหาเรา · แชทไลน์
   *ทำไม:* ชาวสวนเลือกได้ทันทีว่าจะซื้อ อ่าน หรือคุยกับคน
2. **หน้าสินค้า** — เปิดมาเจอ **⭐ ขายดี** ก่อน · เลือกหมวด · ค้นหา · แจ้งชัดว่า **ไม่มีราคา ถามในแชทได้**
   *ทำไม:* สินค้าหลายร้อยตัว — ขายดีขึ้นก่อนช่วยคนส่วนใหญ่ และกันสับสนเรื่องราคาตั้งแต่แรก
3. **เพิ่มลงรายการ** — กด “เพิ่ม” → เป็นปุ่ม − จำนวน + · แถบล่างโชว์ “ดูรายการของฉัน (n)”
   *ทำไม:* ไม่ต้องล็อกอิน รายการเก็บในเครื่อง ปิดแล้วเปิดใหม่ยังอยู่
4. **รายการของฉัน** — แก้จำนวน / ลบ แล้วกด “ยืนยันรายการ”
   *ทำไม:* ตรวจทานก่อน ลดสั่งผิด ร้านไม่ต้องตามแก้
5. **ยืนยัน** — กรอกแค่ **ชื่อเล่น + เบอร์โทร** (ปุ่มส่งเปิดเมื่อกรอกเบอร์)
   *ทำไม:* **ที่เดียวที่ขอข้อมูล และขอตอนท้ายสุด** เบอร์ใช้จับคู่ CRM + ระบบสะสมแต้ม (V2)
6. **ส่งรายการทางไลน์** — ไลน์เปิดที่แชทร้าน **พร้อมข้อความพิมพ์ไว้แล้ว** → ลูกค้ากด “ส่ง” เอง
   *ทำไม:* ออเดอร์เข้าเป็นแชทปกติจากลูกค้า ร้านตอบในแชทเดียวกัน — ไม่ต้องมีระบบหลังบ้าน
7. **ร้านตอบกลับ** — แจ้งราคา เช็กของ ให้คำแนะนำ → ปิดการขาย
   *ทำไม:* จุดแข็งร้านคือคำแนะนำ ดีกว่าตะกร้าอัตโนมัติ

## ทางลัด / ทางออก ที่มีตลอด

- 📞 **โทรสั่ง** — ปุ่มแดงทั้งหน้าแรกและหน้ายืนยัน
- 💬 **แชทเลย** — ปรึกษาโดยไม่ต้องสั่งของ (บอกพืช ระยะ อาการ)
- 🧺 **รายการว่าง** — ชวนกลับไปหน้าสินค้า ไม่ปล่อยให้ตัน
- ↩️ **กลับมาทีหลัง** — รายการค้างไว้ได้
- ❌ **ยกเลิก** — โทรหรือทักไลน์ (บอกไว้ในหน้ายืนยัน)
- 📖 **อ่านแล้วซื้อ** — บทความลิงก์ไปสินค้าที่เกี่ยวข้อง (เฟส 2)

## ฝั่งร้าน

| เมื่อไร | ร้านทำอะไร | เครื่องมือ |
|---|---|---|
| ออเดอร์เข้า | เห็นแชทใหม่ + ชื่อเล่น + เบอร์ + รายการ | LINE OA |
| ตอบกลับ | แจ้งราคา (ปลีก/ส่ง) เช็กของ ให้คำแนะนำ | LINE OA + POS |
| ปิดการขาย | บันทึกการขาย จับคู่ลูกค้าด้วยเบอร์โทร | POS / CRM |
| ภายหลัง | ยอดสะสม + แต้ม ขึ้นหน้าโปรไฟล์ | CRM → เว็บ (V2) |

## กติกาที่ฝังในทุกขั้นตอน

- **ไม่มีราคาบนเว็บ** — ลูกค้าถามราคาเองในแชท ร้านคุมราคาปลีก/ส่งได้เต็มที่
- **ไม่ต้องล็อกอิน** — ไม่ขอข้อมูลจนถึงขั้นสุดท้าย และขอแค่ 2 ช่อง
- **ปุ่มใหญ่ ขั้นตอนน้อย ภาษาชาวสวน** — ถ้าต้องอธิบายวิธีใช้ แปลว่ายากเกินไป
- **โทร/แชทห่างแค่ 1 แตะ** เสมอ
- **ทุกออเดอร์ = ได้เพื่อนใน LINE@ เพิ่ม**
