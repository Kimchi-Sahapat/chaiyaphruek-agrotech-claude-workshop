## On-Page SEO Checklist

### สำหรับทุกหน้า/บทความ
- [ ] Title Tag: 50–60 ตัวอักษร มี keyword หลัก
- [ ] Meta Description: 150–160 ตัวอักษร มี CTA
- [ ] H1: 1 อัน มี keyword หลัก
- [ ] H2/H3: แบ่งเนื้อหา มี keyword รอง
- [ ] URL: สั้น, มี keyword, ใช้ `-` แทนช่องว่าง
- [ ] Alt Text: ทุกรูปภาพ ภาษาไทย+อังกฤษ
- [ ] Internal Links: เชื่อมหน้าที่เกี่ยวข้อง 2–4 ลิงก์
- [ ] Schema Markup: Product, FAQ, Article

### Content SEO
- ความยาว Blog: 1,000–2,000 คำ
- Keyword Density: 1–2% (ไม่ยัด keyword)
- Featured Snippet: ตอบคำถามตรงๆ ในย่อหน้าแรก
- FAQ Section: ท้ายบทความทุกชิ้น

เมื่อรับหัวข้อ ให้สร้าง:

```markdown

[Intro 100 คำ — ตอบคำถามหลักทันที เพื่อ Featured Snippet]

## [H2 — ปัญหาที่เกษตรกรเจอ]
[เนื้อหา 200 คำ]

## [H2 — วิธีแก้ด้วย ChaiXXX]
[เนื้อหา 300 คำ + รูปภาพแนะนำ]

## [H2 — ขั้นตอนการใช้งาน]

## [H2 — ผลลัพธ์ที่ได้]

## คำถามที่พบบ่อย (FAQ)
**Q: ...?**
A: ...

**Q: ...?**

[CTA — ทดลองใช้ฟรี / ติดต่อ]
```

## Technical SEO Checklist (รายเดือน)
- [ ] Page Speed: Core Web Vitals ผ่าน (LCP < 2.5s)
- [ ] Mobile-Friendly: ทดสอบ Google Search Console
- [ ] Crawl Errors: ตรวจและแก้ไข
- [ ] Sitemap: อัปเดตและส่ง Google
- [ ] Backlinks: ตรวจ toxic links
- [ ] Rank Tracking: keywords top 10 มีกี่อัน
