## Voice of Customer (VoC) Analysis

### แหล่งข้อมูล VoC
1. **Facebook Comments/Reviews** — ดู sentiment + keywords ที่ใช้บ่อย
2. **Pantip กระทู้เกษตร** — ปัญหาที่เกษตรกรถามกัน
3. **Google Reviews** — ทั้งของเราและคู่แข่ง
4. **Customer Support Tickets** — ปัญหาที่เจอบ่อย
5. **Post-purchase Survey** — NPS + open-ended feedback
6. **Sales Call Notes** — objections ที่พบบ่อย

### VoC Framework
```
รวบรวม → จัดหมวดหมู่ → หา Pattern → แปลเป็น Insight → Action

Categories:
- Product: "ชอบ/ไม่ชอบอะไรในสินค้า"
- Price: "รู้สึกอย่างไรกับราคา"  
- Service: "ประสบการณ์กับทีมงาน"
- Onboarding: "ติดตั้ง/เริ่มต้นใช้ยาก/ง่ายไหม"
- Results: "ได้ผลลัพธ์ตามที่หวังไหม"
```

## Customer Journey Map

```
AWARENESS
  ↓ เห็น Facebook Ad / TikTok / เพื่อนแนะนำ
CONSIDERATION  
  ↓ เข้าเว็บ, ดู YouTube, เทียบคู่แข่ง, ถามใน Facebook Group
DECISION
  ↓ ขอ Demo, คุยกับ Sales, ดู pricing page
PURCHASE
  ↓ สั่งซื้อ, ชำระ, รอติดตั้ง
ONBOARDING
  ↓ ติดตั้ง, อบรม, ทดลองใช้ครั้งแรก
RETENTION
  ↓ ใช้งานประจำ, ได้ผล, ต่ออายุ
ADVOCACY
  ↓ บอกเพื่อน, รีวิว, กลายเป็น Case Study
```

## CRM Strategy

### Lead Scoring
| Action | คะแนน |
|---|---|
| Download คู่มือฟรี | +5 |
| ดูหน้า Pricing | +10 |
| ขอ Demo | +25 |
| เปิด Email 3 ครั้ง+ | +10 |
| ดู YouTube > 5 วิดีโอ | +15 |
| Score > 40 = Hot Lead | → ส่งให้ Sales |

### Retention Triggers (ส่ง LINE/Email อัตโนมัติ)
- Day 30: "ใช้งานเป็นอย่างไรบ้าง?" + tips
- Day 60: Case study + upsell suggestion
- Day 90 (ไม่ active): Win-back offer
- Birthday/ปีใหม่เกษตร: Special offer + appreciation
