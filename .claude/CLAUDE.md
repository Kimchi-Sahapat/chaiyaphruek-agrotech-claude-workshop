# ชัยพฤกษ์ อโกรเทค — Marketing Agent Workspace

## บริษัท

**ชัยพฤกษ์ อโกรเทค จำกัด (Chaiyaphruek AgroTech Co., Ltd.)**
ก่อตั้ง: 2561 | สำนักงานใหญ่: เชียงใหม่ | สาขา: กรุงเทพฯ, ขอนแก่น, สุราษฎร์ธานี

บริษัทเทคโนโลยีการเกษตรชั้นนำของไทย พัฒนาโซลูชันเกษตรอัจฉริยะ (Smart Farming) เพื่อยกระดับผลผลิตและลดต้นทุนให้เกษตรกรไทย

## กลุ่มเป้าหมาย (Target Audience)

### Primary
- **เกษตรกรรุ่นใหม่ (Young Farmers)** อายุ 25–45 ปี ใช้สมาร์ตโฟน มีพื้นที่ 5–50 ไร่
- **สหกรณ์การเกษตร** ต้องการเครื่องมือรวมข้อมูลสมาชิก
- **ฟาร์มเชิงพาณิชย์ขนาดกลาง** พื้นที่ 50–500 ไร่ ต้องการ ROI ชัดเจน

### Secondary
- หน่วยงานรัฐ (กรมวิชาการเกษตร, กระทรวงเกษตรฯ)
- นักลงทุนด้าน AgriTech
- สื่อมวลชนสายเกษตรและเทคโนโลยี

## Agent Guidelines

เมื่อทำงานด้านการตลาดสำหรับ ชัยพฤกษ์ อโกรเทค:

1. **ใช้ภาษาไทยเป็นหลัก** — เนื้อหาสำหรับ Facebook/LINE/TikTok ใช้ภาษาไทยสุภาพ เป็นกันเอง
2. **ตรวจสอบ Brand Voice** — ไม่ formal เกินไป, ไม่ใช้ศัพท์เทคนิคกับเกษตรกร
3. **อ้างอิง KPI** — ทุก proposal ต้องระบุ KPI ที่วัดได้
4. **ระบุ Channel** — เนื้อหาทุกชิ้นต้องระบุว่าใช้กับ channel ไหน
5. **เก็บ Context** — บันทึก campaign ที่ดำเนินการไปใน project memory
6. **GEO-Ready** — บทความทุกชิ้นต้องมี Answer-Ready paragraph และ FAQ section เพื่อให้ AI Search อ้างอิงได้
